# Week 5: DOM Manipulation

## Project Overview
This repository contains my Week 5 JavaScript DOM Manipulation assignments. It includes an interactive To-Do List, DOM practice exercises, event handling activities, and five daily challenges.

## Project Structure

- `index.html` – Interactive To-Do List
- `styles.css` – To-Do List styling
- `app.js` – To-Do List functionality
- `dom-practice.html` – DOM practice exercises
- `dom.js` – DOM manipulation and event handling exercises
- `daily-challenges/` – Five daily JavaScript challenges

## Features

### To-Do List
- Add tasks using a button or Enter key
- Mark tasks as complete or active
- Delete individual tasks
- Filter all, active, and completed tasks
- Display remaining task count
- Clear completed tasks
- Edit tasks by double-clicking

### DOM Practice
- Selecting and traversing DOM elements
- Modifying HTML content and attributes
- Working with CSS classes
- Creating, inserting, and removing elements
- Handling click, keyboard, and mouse events
- Event delegation and form validation

### Daily Challenges
- Random heading color changer
- Number counter
- Character counter
- Password visibility toggle
- Background color switcher

## Lessons Learned

During this project, I learned how to:
- Select and manipulate HTML elements using JavaScript.
- Respond to user interactions using event listeners.
- Use event delegation to handle dynamically created elements.
- Create, update, and remove DOM elements.
- Validate form inputs.
- Use arrays and objects to manage application data.
- Separate HTML, CSS, and JavaScript responsibilities.
- Use Git and GitHub to track and submit project progress.
